# 심시티 2000 (SimCity 2000) 벤치마킹 및 《화성성역: 정조의 24년》 시스템 매핑 명세서

## 1. 개요 및 모티브 분석
* **원작**: 《SimCity 2000》(1993, Maxis / Will Wright)
* **모티브 적용 프로젝트**: 《화성성역(華城城役): 정조의 24년》
* **목표**: 1990년대 전설적인 도시 시뮬레이터 《심시티 2000》의 검증된 시스템 루프, 2.5D 아이소메트릭 지형 연출, 자율 구획 발전, 조세/예산 딜레마를 18세기 조선 정조 시대의 수원화성 신도시 축조에 1:1로 완벽 고증하여 결합.

## 3. 심시티 2000 특유의 2.5D 비주얼 & 인터페이스 핵심 규격

### 3.1 3D 입체 지형 고저차 (Stepped Cliffs)
* **단면 렌더링**: 타일 간 고도(Elevation 0~4) 차이가 발생할 때 남서측/남동측에 깎아지른 화강암 절벽 단면을 렌더링하여 팔달산 능선과 수원천 협곡의 입체감을 극대화.
* **4방향 90도 회전 시계방향 뷰**: 북서(NW), 북동(NE), 남동(SE), 남서(SW) 시점 전환으로 성벽 뒤편이나 산등성이에 가려진 건물 확인 가능.

### 3.2 연속 드래그 건설 (Drag-to-Build) & 오토타일링 (Autotiling)
* 마우스/터치 드래그 한 번으로 성벽과 삼남대로가 주욱 이어지며, 도로와 성벽이 만날 때는 **4대문(홍예문 + 반원형 옹성 + 2층 단청 문루)**이, 하천과 교차할 때는 **7련 홍예 수문(화홍문)**이 자동으로 올라감.

### 3.3 미니어처 관찰의 맛 (Ambient Crowds)
* 도로 위 보부상(지게와 봇짐장수), 장용영 순찰병, 아궁이 연기, 낟알 쪼는 닭과 오리, 계절별 날씨 파티클(벚꽃, 햇살, 낙엽, 함박눈)을 통해 플레이어가 살아 숨 쉬는 조선 후기 생태계를 관찰하는 재미 제공.
